# Contributing

Read [AGENTS.md](AGENTS.md), [PROJECT_STATE.md](PROJECT_STATE.md), and the relevant documentation before working. Current scope is repository structure and initial documentation only.

Keep contributions small and explain their purpose. Attribute individual work; member assignments are pending. Use descriptive branches (agent-created branches use `codex/`) and commit subjects such as `docs: clarify problem statement`. Reviews should check correctness, evidence, scope, and the student's understanding. Pull requests and further pushes require owner direction.

Do not commit datasets, credentials, virtual environments, caches, or generated model artifacts. Never fabricate research claims or results. Future implementation must document inputs, outputs, assumptions, and meaningful verification. Record only checks actually run. Technical and experimental choices remain proposals until approved.
