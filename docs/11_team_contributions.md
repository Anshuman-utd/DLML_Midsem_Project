# Team contributions

See [PROJECT.md](../PROJECT.md) for the five-member roster. No individual responsibilities are assigned.

Candidate responsibility areas are technical integration and methodology, dataset engineering, EDA and visualization, features and baselines, and ML experiments and evaluation. These are proposals, not assignments.

Before implementation, each task needs a named owner and reviewer, theory prerequisites, inputs, outputs, dependencies, acceptance criteria, and verification steps. All five students should understand and be able to defend the overall project.
